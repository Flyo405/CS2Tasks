# Как выпустить версию

1. Обнови версию в `package.json` и `package-lock.json` командой `npm version patch --no-git-tag-version` или укажи нужный номер вместо `patch`.
2. Запусти `npm test`, закоммить изменения и отправь коммит в GitHub.
3. Поставь тег, совпадающий с версией. Например, для 1.0.0 это `git tag v1.0.0`, затем `git push origin v1.0.0`.
4. В GitHub Actions открой запуск **Windows release**. Он соберёт `CS2Tasks.exe`, посчитает SHA-256 и прикрепит оба файла к черновику релиза.
5. Открой черновик в **Releases**, проверь запуск EXE, допиши заметки и опубликуй как актуальный стабильный релиз. GitHub добавит ссылки на исходники по тегу.

Для проверки обновлений у пользователей репозиторий и релизы должны быть публичными. Первую сборку для публикации бери из Actions, чтобы в EXE был зашит адрес именно этого репозитория.

Перед первой публикацией проверь права на звуки и игровые изображения из файлов с указанием авторов. Лицензия на исходный код отдельно пока не выбрана. Папки `data`, `dist`, `build` и `node_modules` в репозиторий не загружаются.
